# Vinh Vu Tetris Portfolio

A frontend-only, static portfolio with a short Tetris landing game for full-stack development and automation QA recruiters.

## Commands

```bash
npm install
npm run dev
npm run format:check
npm run lint
npm run typecheck
npm run test
npm run test:e2e
npm run build
```

## Content

Replace the explicit placeholders in `src/content/portfolio.ts` with verified profile, experience, and project information. Replace `public/resume-placeholder.pdf` with the real resume before publishing.

The application has no backend, database, authentication, APIs, analytics, or runtime environment variables. Deploy the generated `dist/` directory to a static host.
